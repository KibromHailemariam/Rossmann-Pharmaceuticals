# Week 4 Project: Customer Purchasing Behavior Analysis

## Overview
This project aims to analyze customer purchasing behavior across various stores. The analysis includes exploratory data analysis (EDA) to understand how factors like promotions and store openings affect purchasing behavior.

## Installation
To set up the project, clone the repository and install the required packages:

```bash
pip install -r requirements.txt
```

## Usage
- The main analysis is conducted in the Jupyter notebook located in the `notebooks/` directory.
- Additional scripts and tests can be found in the `scripts/` and `tests/` directories, respectively.

## Logging
This project uses logging to track the steps taken during data analysis. The log file `analysis.log` contains information about data loading, processing, and any errors encountered.
